# Файловые и печатные службы

SMB/NFS/FTP, общие ресурсы, права, квоты
### Файловые и печатные службы

Задача — централизованное хранение файлов и общий доступ к ним и принтерам. Основные протоколы:

| Протокол | Порт         | Назначение                          |
| -------- | ------------ | ----------------------------------- |
| SMB/CIFS | TCP 445 (139) | файлы/принтеры Windows (и Linux через Samba) |
| NFS      | TCP/UDP 2049  | общий доступ в Linux-мире            |
| FTP/FTPS/SFTP | 21 / 990 / 22 | передача файлов                 |
| IPP/CUPS | 631           | печать в Linux                       |

### Общие ресурсы (SMB/Samba)

`/etc/samba/smb.conf`:

```
[share]
  path = /srv/share
  valid users = @staff
  read only = no
  browseable = yes
```

- `smbpasswd -a bob` — пользователь Samba (отдельно от системного);
- `testparm` — проверка конфига; `smbclient -L //server` — просмотр ресурсов;
- **права = пересечение** прав NTFS/Samba и прав файловой системы (POSIX-битов).

### Права и квоты

- **Списки управления доступом (ACL)**: `setfacl -m g:staff:rwx /srv/share`, `getfacl`;
- **наследование** прав на новые файлы (default ACL) — `setfacl -d`;
- **квоты** пользователя/группы: `edquota`, `quotaon`, монтирование с `usrquota,grpquota`;
- **Windows**: NTFS-права (Full/Modify/Read) + шеринг-права; итоговые — самые строгие;
- **маски и umask** в Samba (`create mask`, `directory mask`) задают права новых файлов.

### Печать

- **CUPS** (Linux): веб-интерфейс `http://server:631`, `lpadmin -p HP -E -v ... -m ...`;
- `lp -d HP file`, `lpstat -p` — печать и состояние;
- **Windows Print Server**: роль Print and Document Services, драйверы, публикация в AD;
- права на принтер раздают по группам, чтобы не «печатали все подряд».

<span style="color: 00cc18">Диагностика:</span>

- `smbclient //server/share -U bob`, `mount -t cifs //srv/share /mnt -o user=bob`;
- `showmount -e server`, `exportfs -v` — экспорты NFS;
- `ss -tlnp | grep -E '445|2049|21'` — слушают ли порты.

### Типичные ошибки на экзамене:

- путают **шеринг-права** и **NTFS-права**: доступ определяется пересечением;
- забыли права на **родительские каталоги** — пользователь не может дойти до файла;
- SMB работает, а `hostname`/DNS не резолвится — монтирование по имени падает;
- не открыт порт **445/2049** в файрволе;
- NFS без `no_root_squash`/правильного `exports` — риск или отказ доступа;
- FTP в открытом виде вместо SFTP/FTPS;
- анонимный доступ (`guest ok = yes`) там, где он не нужен;
- квота не включена и «диск переполнен» одним пользователем.
