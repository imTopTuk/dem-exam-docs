# Службы электронной почты

SMTP/IMAP/POP3, MX, релей, антиспам
### Службы электронной почты

Почта состоит из двух частей: **передача** между серверами и **доступ** пользователя к ящику.

| Протокол | Порт(ы)        | Назначение                        |
| -------- | -------------- | --------------------------------- |
| SMTP     | 25 / 587 (submission) / 465 (SMTPS) | отправка и пересылка между серверами |
| IMAP     | 143 / 993      | доступ к ящику, почта хранится на сервере |
| POP3     | 110 / 995      | скачивание, обычно с удалением с сервера |

**IMAP** сейчас основной (синхронизация на нескольких устройствах), **POP3** — устаревший.

### DNS и почта

Для домена нужны записи:

| Тип  | Пример                        | Смысл                     |
| ---- | ----------------------------- | ------------------------- |
| MX   | `example.local. MX 10 mail`   | куда доставлять почту (с приоритетом) |
| A    | `mail.example.local. A 192.168.1.25` | адрес почтового сервера |
| SPF  | `TXT "v=spf1 mx -all"`        | кто вправе отправлять от имени домена |
| DKIM | `TXT` с публичным ключом      | подпись исходящих писем   |
| DMARC| `TXT "_dmarc..."`             | политика при спаме/подделке |

Также корректный **PTR** для IP сервера — иначе многие принимающие серверы отклоняют почту.

### SMTP-сервер

- **Postfix** (`/etc/postfix/main.cf`): `myhostname`, `mydomain`, `myorigin`, `mydestination`, `relayhost`;
- **Exim**, **sendmail** — альтернативы; **Dovecot** — IMAP/POP3 и хранение ящиков (Maildir);
- тестово принять письмо из консоли: `swaks --to bob@example.local`;
- проверить очередь: `postqueue -p`, `mailq`.

### Релей и аутентификация

- **Open relay** запрещён: почта от чужих доменов должна отклоняться;
- **submission 587** + SASL-аутентификация для отправки пользователями;
- релей на relayhost (внешний SMTP) — когда свой сервер не выходит напрямую;
- TLS (STARTTLS/SMTPS) для шифрования канала;
- ограничения: `mynetworks`, `smtpd_recipient_restrictions`.

### Антиспам и защита

- **SpamAssassin** — оценка писем по правилам;
- **GREYLISTING**, RBL-списки, проверка SPF/DKIM/DMARC;
- **антивирус** для вложений (ClamAV);
- **размер письма**, rate limit, отказ от приёма bounces.

### Типичные ошибки на экзамене:

- нет записи **MX** или она указывает не туда — почта не доставляется;
- сервер открыт как **open relay** — мгновенно попадает в чёрные списки;
- нет **PTR** — принимающая сторона отвергает письма;
- забыли SPF/DKIM/DMARC — уходит в спам;
- порт 25 закрыт у провайдера — используют relayhost/587;
- сертификат не на то имя в SMTPS/IMAPS — клиент ругается;
- ящики без квот — диск переполняется;
- один сервер и для ящиков, и для рассылок — репутация страдает.
