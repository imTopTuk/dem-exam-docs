# Windows Server и Active Directory

роли, домен, контроллер домена, GPO
### Windows Server и Active Directory

Windows Server строят по **ролям и компонентам**: устанавливают только нужное (AD DS, DNS, DHCP, File Server, IIS, Hyper-V). Базовая настройка — имя, статический IP, часовой пояс, обновления.

### Active Directory (AD DS)

AD — служба каталога, хранит объекты (пользователи, компьютеры, группы) и управляет доменом. Ключевые понятия:

| Термин | Смысл |
| ------ | ----- |
| Домен | административная граница, например `example.local` |
| Контроллер домена (DC) | сервер с ролью AD DS, хранит базу `NTDS.dit` |
| Лес / дерево | совокупность доменов, общий каталог |
| OU (подразделение) | контейнер для делегирования прав и GPO |
| Группа | `Global`, `Domain Local`, `Universal` — раздача прав |
| SYSVOL | общий каталог с политиками и скриптами |

**Продвижение в DC:** `Install-WindowsFeature AD-Domain-Services` + `Install-ADDSForest -DomainName example.local`. Перед этим — статический IP и корректный **DNS** (AD опирается на DNS-записи `_ldap._tcp`).

<span style="color: 00cc18">Ключевые команды (PowerShell):</span>

- `New-ADUser -Name bob -SamAccountName bob -Enabled $true -Path "OU=Users,..."`;
- `Add-ADGroupMember "Domain Admins" bob`;
- `Get-ADUser bob`, `Get-ADComputer -Filter *`;
- `dcdiag`, `repadmin /replsummary` — диагностика и репликация;
- `gpupdate /force`, `gpresult /r` — применение и отчёт GPO.

### Групповые политики (GPO)

GPO — централизованные настройки для OU/домена/сайта (парольные политики, обои, запреты, скрипты, маппинг дисков). Применяются по порядку: **site → domain → OU**, побеждает более близкая политика (последняя). Адресация через `\\example.local\SYSVOL`.

- парольные политики живут в **Default Domain Policy** (длина, история, блокировка);
- **RSAT** даёт оснастки `dsa.msc`, `gpmc.msc` для управления с рабочей станции.

### Роли и сервисы

- **DNS** — обычно на DC, зона интегрирована в AD (`Secure only updates`);
- **DHCP** — авторизуется в AD, чтобы не выдавать левые адреса;
- **File Server / IIS / Hyper-V** — разворачиваются как отдельные роли;
- **Licensing/WSUS** — обслуживание обновлений.

### Типичные ошибки на экзамене:

- DC получает IP по DHCP — недопустимо: у контроллера домена **статический** адрес;
- некорректный DNS (DHCP/DNS хоста не указывают на себя/DC) — AD не продвигается;
- один DC — единая точка отказа; нужен второй + репликация;
- привязка сервисов к **администратору домена** вместо сервисных учёток;
- GPO применяют не к той OU или блокируют наследование — «политика не работает»;
- забыли `gpupdate`/время синхронизации — GPO расходится;
- сложные имена DC несовместимы с криптоключами/сертификатами;
- откат контроллера домена без бэкапа системного состояния.
