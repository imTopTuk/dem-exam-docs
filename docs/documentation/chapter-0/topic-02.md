# Структура и оценивание

Экзамен состоит из **трех заданий**, которые выполняются последовательно.

**Структура заданий и время:**

| №         | Название задания                             | Время (ГИА БУ)        | Время (ГИА ПУ)          |
| --------- | -------------------------------------------  | --------------------- | ----------------------- |
| 1         | Настройка сетевой инфраструктуры             | 1 час (60 мин)        | 1 час (60 мин)          |
| 2         | Организация сетевого администрирования       | 1 час (60 мин)        | Входит в общее время ПУ |
| 3         | Эксплуатация объектов сетевой инфраструктуры | 1 час 30 мин (90 мин) | Входит в общее время ПУ |
| **Итого** | **Максимальная продолжительность**           | **3 ч. 30 мин.**      | **4 ч. 00 мин.**        |

**Оценивание:**

- **Максимальный балл:**
    - Для ПА (промежуточной аттестации) — 25 баллов.
    - Для ГИА ДЭ БУ (базовый уровень) — 75 баллов.
    - Для ГИА ДЭ ПУ (профильный уровень) — 100 баллов (75 инвариант + 25 вариатив).
- **Критерии:** Эксперты оценивают как итоговый продукт (работоспособность сети и сервисов), так и процесс (правильность настроек).
- **Отчетность:** По каждому заданию вам необходимо вести отчет. Итоговый файл сохраняется на рабочем столе с именем `ФамилияУчастникаЗадание1` (и так далее для каждого задания). В отчете должны быть текстовые описания и скриншоты, подтверждающие выполнение.
