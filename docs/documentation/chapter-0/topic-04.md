# Типовые сценарии заданий

Задания построены по принципу «от простого к сложному» и имитируют работу администратора в филиальной сети (HQ — головной офис, BR — филиал).

### Задание 1. Настройка сетевой инфраструктуры (База)

- **Суть:** Создание фундамента сети.
- **Что делать:** Присвоить имена устройствам (FQDN), рассчитать IP-адресацию (с учетом требований к размеру подсетей), настроить VLAN (100, 200, 999), настроить доступ в Интернет (NAT), поднять GRE-туннель между офисами, настроить динамическую маршрутизацию OSPF с аутентификацией MD5, поднять DHCP и DNS-сервер.
- **Ключевой навык:** Работа с командной строкой маршрутизаторов (EcoRouter/Linux) и понимание принципов маршрутизации.

### Задание 2. Организация сетевого администрирования (Инфраструктура)

- **Суть:** Настройка сервисов на предварительно настроенном стенде.
- **Что делать:** Ввести клиентскую машину (HQ-CLI) в домен Samba DC, настроить политику паролей и группы, собрать RAID-массив (уровень 0) на сервере, настроить NFS, Chrony (NTP), Ansible (инвентарь), развернуть веб-приложения в Docker и Apache+MariaDB, настроить статический NAT (проброс портов) и установить Яндекс.Браузер.
- **Ключевой навык:** Работа с серверными ОС Linux, понимание принципов работы домена, веб-серверов и контейнеризации.

### Задание 3. Эксплуатация объектов сетевой инфраструктуры (Безопасность и мониторинг)

- **Суть:** Обеспечение безопасности и отказоустойчивости.
- **Что делать:** Импортировать пользователей в домен скриптом, настроить обратный прокси (Nginx) на ISP для веб-сайтов, настроить web-аутентификацию, развернуть центр сертификации (CA) на HQ-SRV и настроить HTTPS, настроить мониторинг (atop) и принт-сервер (CUPS), настроить сбор инвентаризации через Ansible, защитить SSH через fail2ban и настроить резервное копирование (Кибер Бэкап).
- **Ключевой навык:** Обеспечение ИБ, работа с сертификатами и системами резервного копирования.
