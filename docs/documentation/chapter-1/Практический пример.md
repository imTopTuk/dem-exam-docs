# Практический пример

## VLSM-пример по шагам
**Зачем вообще формулы.** Без них пришлось бы подбирать маску наугад. Формулы отвечают на три вопроса, которые задают в каждой задаче:

1. Какую маску выбрать под нужное число хостов?
2. С какого до какого адреса идёт подсеть?
3. Входит ли конкретный хост в эту подсеть?

**Дано:** сеть `192.168.1.0/24`, нужно: отдел А: 100 хостов, отдел Б: 50 хостов, канал между роутерами: 2 хоста.

### Шаг 1. Находим префикс для каждой подсети

Формула: **хостов = 2^n − 2**, где n это число бит, оставленных под хосты. Ищем наименьшее n, при котором хостов хватает. Потом **префикс = 32 − n**.

**Отдел А (100):**

- n = 6: 2⁶ − 2 = 62, мало
- n = 7: 2⁷ − 2 = 126 ≥ 100, подходит
- префикс = 32 − 7 = **/25**, размер блока 2⁷ = **128** адресов

**Отдел Б (50):**

- n = 5: 2⁵ − 2 = 30, мало
- n = 6: 2⁶ − 2 = 62 ≥ 50, подходит
- префикс = 32 − 6 = **/26**, размер блока **64**

**Канал (2):**

- n = 1: 2¹ − 2 = 0, мало
- n = 2: 2² − 2 = 2, подходит
- префикс = 32 − 2 = **/30**, размер блока **4**

### Шаг 2. Раскладываем блоки подряд (от большего к меньшему)

Формулы для каждого блока:

- **адрес сети** = начало блока (для первого блока это начало исходной сети)
- **broadcast** = адрес сети + размер блока − 1
- **хосты** = от (сеть + 1) до (broadcast − 1)
- **начало следующего блока** = broadcast + 1

**Отдел А:**

- сеть: `192.168.1.0`
- broadcast: 0 + 128 − 1 = 127 → `192.168.1.127`
- хосты: `.1` – `.126`

**Отдел Б:** начинается там, где закончился А (127 + 1 = 128)

- сеть: `192.168.1.128`
- broadcast: 128 + 64 − 1 = 191 → `192.168.1.191`
- хосты: `.129` – `.190`

**Канал:** начинается с 191 + 1 = 192

- сеть: `192.168.1.192`
- broadcast: 192 + 4 − 1 = 195 → `192.168.1.195`
- хосты: `.193` – `.194`

Свободно: `.196` – `.255` (можно делить дальше).

|Подсеть|Сеть|Хосты|Broadcast|
|---|---|---|---|
|А|192.168.1.0/25|.1 – .126|.127|
|Б|192.168.1.128/26|.129 – .190|.191|
|Канал|192.168.1.192/30|.193 – .194|.195|

### Шаг 3. Проверка: в какой подсети хост

Хост `192.168.1.150`, проверяем по маске `/26` (255.255.255.192). Здесь и нужен AND, смотрим последний октет:

```
150 = 10010110
192 = 11000000
AND = 10000000 = 128
```

Получили адрес сети `192.168.1.128`, значит, хост из подсети отдела Б. Это совпадает с таблицей: 150 попадает в диапазон .129 – .190.

### Мини-шпаргалка

|Что нужно|Формула|
|---|---|
|Хостов в подсети|2^(32−n) − 2|
|Размер блока|2^(32−n)|
|Префикс под N хостов|32 − n, где 2^n − 2 ≥ N|
|Broadcast|сеть + размер − 1|
|Следующая сеть|broadcast + 1|
|Адрес сети хоста|IP AND маска|
