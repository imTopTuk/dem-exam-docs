# 1. Базовая настройка сетей (Задание 1 ДЭ)

## Раздел/тема
1. [IP-адресация](IP-адресация.md) - Расчет подсетей (VLSM), приватные диапазоны, маски
2. [Базовая настройка](Базовая настройка.md) - hostname, FQDN, синхронизация времени (NTP/Chrony)
3. [Коммутация L2](Коммутация L2.md) - VLAN, Access/Trunk порты, Router-on-a-Stick
4. [Маршрутизация](Маршрутизация.md) - Статические маршруты, OSPF (метрики, MD5-аутентификация)
5. [Туннелирование](Туннелирование.md) - Настройка GRE-туннелей, инкапсуляция трафика
6. [Трансляция адресов](Трансляция адресов.md) - NAT, PAT, SNAT, DNAT (проброс портов)
7. [Служба DHCP](Служба DHCP.md) - Настройка пулов, исключений, опций (шлюз, DNS, суффикс)
8. [Служба DNS](Служба DNS.md) - Прямые (A) и обратные (PTR) зоны, forwarders
9. [Удаленный доступ](Удаленный доступ.md) - SSH (смена порта, запрет root, ограничение попыток, баннеры
