# ПЛК, HMI и SCADA

цикл ПЛК, языки МЭК 61131-3, диспетчеризация
### ПЛК, HMI и SCADA

### ПЛК (программируемый логический контроллер)

ПЛК — промышленный компьютер, управляющий процессом по программе. Работает **циклически**:

1. **чтение входов** (датчики, кнопки);
2. **выполнение программы** (логика);
3. **запись выходов** (пускатели, клапаны, приводы).

Цикл (scan time) — обычно миллисекунды; от него зависит время реакции. ПЛК рассчитан на тяжёлые условия, помехи и круглосуточную работу.

Состав: процессорный модуль, модули ввода/вывода (дискретные/аналоговые), коммуникационные модули, блок питания.

### Языки МЭК 61131-3

| Язык | Аббревиатура | Область                |
| ---- | ------------ | ---------------------- |
| Ladder (релейная логика) | LD | дискретная логика, электрики |
| Function Block Diagram   | FBD | функциональные блоки   |
| Structured Text          | ST | сложные алгоритмы (похож на Pascal) |
| Instruction List         | IL | низкоуровневый (устаревает) |
| Sequential Function Chart| SFC | последовательности шагов |

### HMI и SCADA

- **HMI** (Human-Machine Interface) — локальная панель оператора: кнопки, индикация, мнемосхемы. Отдельная панель или ПК.
- **SCADA** — супервизорный сбор данных и диспетчерское управление: мнемосхемы, тренды, архив, аварии, права операторов, резервирование.
- **OPC UA** — современный стандарт обмена ПЛК ↔ SCADA ↔ MES с адресацией и шифрованием (замена устаревшего OPC DA).

Поток данных: датчик → ПЛК → SCADA/HMI → архив/MES → оператор.

### Резервирование

- горячий резерв **ПЛК** (два процессора, синхронизация);
- резервирование **SCADA-серверов** и каналов связи;
- **watchdog** и безопасные состояния при отказах (fail-safe).

### Типичные ошибки на экзамене:

- путают **HMI** (локальная панель) и **SCADA** (система диспетчеризации);
- не учитывают **scan time** при расчёте реакции системы;
- логику ведут на «дешёвом» языке там, где нужен ST/SFC, и наоборот;
- нет резервирования ПЛК/каналов на критичном объекте;
- OPC с настройками по умолчанию и без аутентификации;
- время на ПЛК/SCADA/серверах не синхронизировано — тренды и аварии «плывут»;
- отсутствует fail-safe: при отказе оборудование остаётся в опасном положении;
- прошивку/программу меняют без бэкапа проекта.
