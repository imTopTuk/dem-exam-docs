# Аутентификация и управление доступом

AAA, RADIUS/TACACS+, RBAC, MFA
### Аутентификация и управление доступом

Классическая формула — **AAA**:

- **Authentication** — кто ты (логин/пароль, ключ, сертификат, MFA);
- **Authorization** — что тебе можно;
- **Accounting** — что ты делал (аудит и биллинг).

### Факторы аутентификации

| Тип        | Пример                         |
| ---------- | ------------------------------ |
| Знание     | пароль, PIN                     |
| Владение   | токен, смартфон (OTP), ключ     |
| Биометрия  | отпечаток, лицо, голос          |

**MFA** — комбинируют минимум два разных фактора; **2FA** — ровно два. Пароль в одиночку считается устаревшим.

### Протоколы и серверы

| Протокол  | Транспорт | Особенность                       |
| --------- | --------- | --------------------------------- |
| RADIUS    | UDP 1812/1813 | стандарт для сети/802.1X/VPN    |
| TACACS+   | TCP 49    | детальная авторизация команд (Cisco) |
| Kerberos  | TCP/UDP 88 | единый вход в домен AD            |
| LDAP/AD   | TCP 389/636 | каталог пользователей            |

- центральные серверы: FreeRADIUS, Windows NPS, AD;
- оборудование настраивают на **AAA-сервер**, локальная база — резерв.

### Управление доступом

- **RBAC** (роли): администратор, оператор, аудитор, пользователь — права по ролям, а не персонально;
- **принцип минимальных привилегий** и разделение обязанностей;
- **сервисные учётки** без интерактивного входа, с чётким владельцем;
- **парольная политика**: длина, сложность, срок, история, блокировка после неудач;
- учёт рабочего «админ vs рутинный» — не работать постоянно под root/админом;
- своевременное **отключение** уволенных и устаревших учёток.

### Типичные ошибки на экзамене:

- один общий «admin» на всех — нет подотчётности;
- пароль хранят в открытом виде, рассылают по почте;
- MFA есть, но её можно обойти (fallback по паролю без контроля);
- нет учёта (accounting) — нельзя разобрать инцидент;
- локальная база на оборудовании остаётся с заводским паролем;
- сервисные учётки с бессрочным паролем и правами домена;
- не отключают учётки уволенных;
- права раздают «на всякий случай», без периодического пересмотра.
