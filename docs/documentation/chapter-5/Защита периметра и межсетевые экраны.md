### Защита периметра и межсетевые экраны

Межсетевой экран (**firewall**) фильтрует трафик между зонами доверия по правилам. Это основной рубеж на границе сети.

### Типы межсетевых экранов

| Тип          | Что анализирует            | Уровень OSI |
| ------------ | -------------------------- | ----------- |
| Пакетный (stateless) | адреса/порты/флаги  | 3–4         |
| Stateful     | состояние соединений       | 3–4         |
| Application (proxy) | содержимое протокола | 7           |
| **NGFW**     | DPI, приложения, IPS, TLS   | 3–7         |
| WAF          | веб-трафик (HTTP/HTTPS)     | 7           |

**DMZ** — буферная зона для публичных сервисов: между интернетом и внутренней сетью, чтобы компромисс сервера не давал доступ внутрь.

### Правила и ACL

- политика по умолчанию — **deny all** (запретить всё, разрешать точечно);
- порядок правил важен: сверху — конкретные, снизу — общие;
- **ACL** — списки доступа: `permit`/`deny` по IP, портам, протоколам;
- **best practice**: логовать запреты, называть правила, ревизовать устаревшие.

```
# nftables: разрешить SSH только из admin-сети, остальное — дропнуть
nft add rule inet filter input ip saddr 192.168.1.0/24 tcp dport 22 accept
nft add rule inet filter input tcp dport 22 drop
```

- **Cisco ACL**: `access-list 100 permit tcp 192.168.1.0 0.0.0.255 any eq 443`, потом `ip access-group 100 in`;
- в конце неявный `deny any`.

### Зоны и сегментация

- зоны доверия: интернет (untrust), DMZ, пользователи, серверы, управление (management), OT;
- между зонами — правила «кто к кому и по какому порту»;
- отдельная **management-сеть** для администрирования оборудования.

### IDS/IPS

- **IDS** — обнаруживает и сообщает (пассивно);
- **IPS** — блокирует (в разрыв);
- сигнатуры + аномалии; Suricata, Snort; интеграция с SIEM.

### Типичные ошибки на экзамене:

- правило «any → any permit» сверху — файрвол превращается в маршрутизатор;
- нет правила по умолчанию **deny**;
- путают порядок правил: общее перекрывает частное;
- публичные сервисы ставят напрямую во внутреннюю сеть, без DMZ;
- управляют оборудованием из той же сети, что и пользователи;
- NAT «считают» защитой — это трансляция, а не фильтр;
- не обновляют сигнатуры IDS/IPS;
- правила «на всякий случай» живут годами без ревизии.
