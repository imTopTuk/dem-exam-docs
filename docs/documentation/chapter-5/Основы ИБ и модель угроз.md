# Основы ИБ и модель угроз

CIA, угрозы/уязвимости/риски, модель нарушителя
### Основы ИБ и модель угроз

Информационная безопасность защищает три свойства информации (**триада CIA**):

| Свойство         | Смысл                                  | Нарушение            |
| ---------------- | -------------------------------------- | -------------------- |
| Конфиденциальность | доступ только уполномоченных          | утечка данных         |
| Целостность      | данные не изменены незаметно            | подмена, порча        |
| Доступность      | данные/сервис доступны, когда нужно     | отказ в обслуживании  |

Дополнительно выделяют **неотказуемость** (доказательство авторства) и **подотчётность** (аудит).

### Основные понятия

- **Актив** — то, что защищаем (данные, сервис, оборудование);
- **Угроза** — потенциальная опасность;
- **Уязвимость** — слабое место, через которое угроза реализуется;
- **Атака** — реализация угрозы через уязвимость;
- **Риск** = вероятность × ущерб. Рисками **управляют**: снижают, принимают, передают, избегают.

### Модель нарушителя

Описывает, **кто** и **с какими возможностями** может атаковать:

- внешний/внутренний нарушитель;
- уровень возможностей: скрипт-кидди, хакер, организованная группа, спецслужбы, инсайдер;
- точка доступа: интернет, Wi-Fi, USB, подрядчик, физический доступ.

### Виды атак (кратко)

| Атака                | Суть                              | Защита                  |
| -------------------- | --------------------------------- | ----------------------- |
| Фишинг / социнженерия | обман пользователя               | обучение, почтовые фильтры |
| Brute force          | подбор пароля                     | сложные пароли, MFA, fail2ban |
| MITM                 | перехват/подмена в канале          | TLS/VPN, сертификаты    |
| DoS/DDoS             | перегрузка                        | лимиты, защита у провайдера |
| SQL-инъекция         | внедрение кода через ввод          | параметризация, WAF     |
| XSS/CSRF             | атаки на веб-пользователя          | экранирование, токены   |
| Ransomware           | шифрование данных                  | бэкапы, сегментация, EDR |

### Принципы защиты

- **эшелонированная оборона** (defense in depth) — несколько рубежей;
- **минимальные привилегии** и **zero trust**;
- **принцип необходимого знания**;
- регулярные обновления и аудит.

### Типичные ошибки на экзамене:

- путают **угрозу**, **уязвимость**, **атаку** и **риск**;
- считают защиту «одним файрволом» — нет эшелонирования;
- игнорируют внутреннего нарушителя;
- не оценивают риск по вероятности и ущербу;
- защищают только периметр, забывая о шифровании данных;
- не обучают пользователей — фишинг обходит любую технику;
- разово «провели аудит» и успокоились вместо постоянного процесса.
