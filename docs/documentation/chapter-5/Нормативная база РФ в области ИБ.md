# Нормативная база РФ в области ИБ

ФЗ-152, ФСТЭК, ГОСТ, КИИ, аттестация
### Нормативная база РФ в области ИБ

Для специалиста важно знать, **какими документами** регламентируется защита информации в РФ и какие требования обязательны.

### Основные законы

| Документ | Смысл                                                  |
| -------- | ------------------------------------------------------ |
| **ФЗ-152** «О персональных данных» | защита ПДн, согласие субъекта, уровни защищённости (УЗ-1..4) |
| **ФЗ-149** «Об информации…» | общие принципы, ограничение доступа          |
| **ФЗ-187** «О безопасности КИИ» | категорирование значимых объектов, требования к субъектам КИИ |
| ФЗ-63 «Об электронной подписи» | виды ЭП, удостоверяющие центры              |

### Регуляторы и документы

- **ФСТЭК России** — техническая защита, приказы (в т.ч. приказ № 17 для ГИС, № 21 для ПДн), банк угроз;
- **ФСБ России** — криптография, приказы по СКЗИ, требования к средствам защиты;
- **ГОСТ** — стандарты (ГОСТ Р 34.10/34.11 — криптография; серия 27000-подобных по менеджменту ИБ);
- **Банк России** (для финсектора), **Минцифры**, **Роскомнадзор** (надзор за ПДн);
- **приказы по аттестации объектов информатизации**.

### Уровни защищённости ПДн (ФЗ-152 / приказ ФСТЭК № 21)

Уровень зависит от типа ПДн и числа субъектов:

| Уровень | Пример условий                          |
| ------- | --------------------------------------- |
| УЗ-1    | специальные категории/биометрия, много субъектов |
| УЗ-2    | специальные категории, ограниченное число |
| УЗ-3    | общедоступные/иные ПДн, крупные системы  |
| УЗ-4    | иные ПДн, ограниченное число субъектов   |

Требования: организационные, режим помещений, учёт носителей, СКЗИ, антивирус, СЗИ, контроль.

### Аттестация и сертификация

- **аттестация объекта информатизации** — подтверждение соответствия требованиям (обязательна для ГИС, ИСПДн, КИИ по режиму);
- **сертификация СЗИ** — использовать средства, прошедшие сертификацию ФСТЭК/ФСБ, из реестра;
- **импортозамещение** — реестр отечественного ПО, ОС (Astra Linux, RedOS, Alt), ПАК;
- **лицензирование** деятельности (техзащита КИ, криптография — ФСБ).

### Практические следствия

- определить, какие данные обрабатываются (ПДн? КИИ? ГИС?);
- выбрать уровень/класс и набор мер;
- вести документацию: модель угроз, приказы, журналы, регламенты;
- применять **сертифицированные** средства и отечественную криптографию;
- своевременно уведомлять регуляторов об инцидентах.

### Типичные ошибки на экзамене:

- не определили, что в системе **ПДн**/объект **КИИ** — меры взяты наугад;
- используют **неcertified** СКЗИ/СЗИ там, где требуется сертификация;
- определили неверный уровень защищённости (УЗ);
- нет модели угроз и организационной документации;
- применяют только технические меры, забывая об организационных и режимных;
- не уведомляют Роскомнадзор/ФСТЭК как положено;
- хранят ПДн без правовых оснований и согласия;
- игнорируют требование локального хранения/импортозамещения.
