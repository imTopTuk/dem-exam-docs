# Welcome

Всё, что нужно для подготовки к демонстрационному экзамену по специальности **09.02.06 «Сетевое и системное администрирование»**.

## Главная цель проекта

Собрать теорию и практические разборы в одном месте, чтобы перед экзаменом не искать сведения по разным конспектам и форумам. Документация помогает быстро закрыть конкретный пробел: от расчёта VLSM до настройки домена, мониторинга или VPN.

## Что здесь будет

| Раздел | Содержание |
|---|---|
| **0. Введение** | Формат экзамена, оценивание и правила работы |
| **1. Базовая настройка сетей** | Адресация, VLAN, маршрутизация, NAT, DHCP, DNS, SSH |
| **2. Сетевое администрирование** | Linux, Windows Server, AD, службы и контейнеры |
| **3. Эксплуатация и мониторинг** | Мониторинг, логи, диагностика, IaC, бэкапы, ITSM |
| **4. Промышленные сети** | Purdue, ПЛК, SCADA, промышленные протоколы |
| **5. Безопасность** | Модель угроз, VPN, PKI, защита хостов и реагирование |

## Что посмотреть первым

1. Прочитайте главу **0**, чтобы понять правила и критерии.
2. Последовательно разберите главы **1–3** — это практическая основа.
3. Переходите к главам **4–5** для закрытия профессиональных модулей.

!!! info "Если времени мало"
    Сначала изучайте формулы, примеры конфигураций и блоки с типичными ошибками. Теоретические подробности можно читать по мере необходимости.
