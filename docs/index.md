## Маршрут подготовки

<div class="learning-path" markdown>

1. **Пойми формат** — начни с введения и критериев оценивания.
2. **Закрой сетевую базу** — адресация, VLAN, маршрутизация и сетевые службы.
3. **Настрой инфраструктуру** — Linux, Windows Server, домен и контейнеры.
4. **Научись эксплуатировать** — мониторинг, логи, бэкапы и ITSM.
5. **Углуби профиль** — АСУ ТП и безопасность инфраструктуры.

</div>

## Need some help?

??? question "С чего начать, если я новичок?"
    Откройте [Welcome](documentation/welcome.md), затем проходите главы по порядку от 0 до 5. Главы 1–3 — главный приоритет для практической части.

??? question "Где искать команды и конфигурации?"
    Они находятся прямо внутри тематических страниц. Используйте поиск в верхней панели по названию службы или команды.
